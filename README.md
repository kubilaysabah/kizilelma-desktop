# Kızılelma masaüstü

Kızılelma'nın masaüstü uygulamasının indirme dosyaları. Bu depoda kod yok; yalnızca sürümler var.

**İndir:** [kizilelma.app/indir](https://kizilelma.app/indir) ya da sağdaki **Releases** bölümü.

| Sistem | Dosya |
| --- | --- |
| Windows 10 ve 11 (x64) | `Kizilelma-Windows-x64-Setup.exe` |
| Linux (x86_64) | `Kizilelma-Linux-x86_64.AppImage` |
| macOS | Yakında |

## Kurulum

- **Windows:** Kurulum dosyasını çalıştır. Uygulama henüz imzalı olmadığı için Windows "bilinmeyen yayıncı" uyarısı gösterebilir: **Ek bilgi › Yine de çalıştır**.
- **Linux:** Dosyayı çalıştırılabilir yap ve aç: `chmod +x Kizilelma-Linux-x86_64.AppImage && ./Kizilelma-Linux-x86_64.AppImage`. Oturum masaüstünün anahtarlığında (GNOME Keyring, KWallet) saklanır.

Tarayıcıda kurulum gerekmeden: [app.kizilelma.app](https://app.kizilelma.app)
